01 / the object level TOY MODEL

Start with a world that does not understand.

A formal system is a machine with an alphabet, rules for forming strings, axioms, and rules of inference. It does not need to know what its symbols mean. It only needs to apply the rules exactly.

Our toy system starts with A. Its rules are A → AB and B → BA. A string is not yet a theorem; it becomes one only when we can show its derivation.

02 / derivation STANDARD

A theorem is a history.

“True” is not the first question inside a formal system. The first question is: can this string be reached from the axioms by the permitted rules?

03 / the first limit GEB

Generating proofs is not the same as deciding theoremhood.

A proof checker can verify a proposed proof. A proof generator can keep producing theorems. But a decision procedure must always halt and answer YES or NO for an arbitrary candidate.

For a theorem, searching eventually finds a proof. For a non-theorem, the same search may simply continue. The missing proof is not itself a terminating answer.

04 / the turn inward GEB

Self-reference is a change in what a statement can point to.

First, a string points to another string. Then a string points to a description. The dangerous move is when the description is allowed to become input again.

statement→another statement
statement→its description
statement↺its own description

The loop is not the word “self.” It is a real substitution in which a description is returned to the construction.

05 / syntax becomes arithmetic GEB + STANDARD

Give every symbol a number.

Gödel's move is not to claim that strings secretly are numbers. It is to build a mechanical, uniquely decodable correspondence. Once a string has a code, arithmetic can operate on the code.

This page uses a small positional toy code. TNT uses a more elaborate Gödel numbering. The point is the same: syntax becomes an object that number theory can describe.

06 / the great trick STANDARD

A description can be applied to the thing it describes.

Diagonalization is the construction that turns “a formula with a free place” into a formula that receives its own code. This is the engine behind the self-reference, not an infinite mirror.

07 / construct G STANDARD / PEDAGOGICAL MODEL

Now make the system speak about its own proofs.

Let ProofS(p, q) mean: p codes a valid proof in S of the formula whose code is q. Let ProvS(q) mean: some p is a proof code for q.

The diagonal construction produces a sentence G that is equivalent to:

G ↔ ¬ProvS(⌜G⌝)

In the intended arithmetic interpretation, G says: “G is not provable in S.” It is built from encoding and substitution; it is not smuggled in as a slogan.

proof predicate
self-code ⌜G⌝
G : ¬ProvS(⌜G⌝)

09 / two viewpoints STANDARD

Truth and provability are different relations.

From inside S, the question is whether a formal derivation exists. From an external meta-level, we can reason about what the encoded sentence says in the intended model of the natural numbers.

Under the appropriate soundness condition, G is true in that intended interpretation because it really has no S-proof. That does not mean every unprovable sentence is true.

inside Sno proof found
external arithmetic viewG is true if S is sound here

Move between the relations. The sentence stays fixed; the viewpoint changes.

11 / a different substrate STANDARD

Now replace proofs with programs.

The Halting Problem is not Gödel's theorem. It is a theorem about computation. The connection is that both can encode descriptions and then feed a description back into the mechanism.

D(P):

The hypothetical oracle looks perfect until D is given its own code.

12 / related, not identical STANDARD

Two machines. One family resemblance.

Gödel uses syntax, arithmetic coding, and provability. Turing uses programs, inputs, and behavior. Their substrates differ, but diagonal self-application defeats a complete internal procedure in each setting.

Turing
