# Visual language

## One evolving instrument

The page uses a dark observatory field, but atmosphere remains subordinate to mechanism. No decorative particle cloud is allowed without a corresponding mathematical object.

### Objects

- Amber nodes: axioms or accepted inputs.
- Blue nodes: mechanically generated formulas and proof steps.
- White nodes: encoded syntax or numeral representations.
- Red nodes: contradiction, failed branch, or unavailable decision.
- Violet nodes: meta-level or external interpretation.
- Thin lines: permitted relation or translation.
- Thick flowing lines: active derivation or computation.
- Empty space: an unvisited or unreachable possibility; it is not automatically “false.”

### Geometry by stage

- Stage 1: a small planar alphabet and rule rails.
- Stage 2: a branching proof tree.
- Stage 3: a vertical stack showing proof enumeration beside decision.
- Stage 4: closed reference arcs.
- Stage 5: symbol strings become numbered columns.
- Stage 6: the diagonal path bends from a function description back into its input.
- Stage 7: a suspended node G sits inside the system graph while an external violet path can identify its interpretation.
- Stage 8: two proof branches diverge and receive explicit statuses.
- Stage 9: a second shell grows around the first system.
- Stage 10: the shell becomes a program trace and then a self-feeding diagonal machine.
- Stage 11: the whole instrument folds into a hierarchy with the earlier G node visible inside it.

## Motion grammar

- Scroll advances conceptual state, not merely camera position.
- Play animates a real derivation or state transition.
- Step advances exactly one proof, encoding, or computation transition.
- Pause freezes both text and scene.
- Reset returns the current mechanism to its initial state.
- Camera elevation marks movement from object level to meta-level.

## Typography

Use an expressive serif for mathematical exposition and a restrained monospace for strings, codes, and machine output. Equations are large and spacious. Technical labels are small but never carry essential explanation alone.

## Deliberate restraint

Avoid floating cards, decorative orbs, generic dashboard chrome, and random animation. The viewer should always be able to answer: what object is moving, what rule moved it, and what did the movement establish?
