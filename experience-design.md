# Experience design: Gödel's First Incompleteness Theorem

## Premise

This is one long mathematical journey, not a dashboard. The user begins with meaningless marks and ends with a precise understanding of why a sufficiently expressive, effectively axiomatized, consistent formal system cannot decide every arithmetic statement.

The page follows one persistent object: a proof machine. At first it accepts symbols and rules. Later it accepts encodings of its own syntax. Near the climax, a statement built from that machine becomes an object the machine cannot settle.

## Conceptual progression

1. Formal system: alphabet, axioms, rules, strings.
2. Mechanical manipulation: syntax can be operated without understanding.
3. Proof and theoremhood: a theorem is a derivable string.
4. Enumeration vs decision: proofs can be generated while theoremhood may resist a terminating yes/no test.
5. Self-reference: a statement can refer to its own description.
6. Encoding: symbols, strings, derivations, and rules receive numerical codes.
7. Diagonalization: a description is fed its own code.
8. Gödel sentence: a sentence G is constructed that says, in the relevant arithmetical interpretation, that G is not provable in S.
9. Incompleteness: under the stated assumptions, S cannot prove G; under stronger assumptions it also cannot prove its negation.
10. Truth and provability: external truth in the intended model is not the same relation as formal derivability.
11. Strengthening: adding G produces a stronger system, not a final system.
12. Computation: the Halting Problem uses a different substrate but a related diagonal obstacle.
13. Outside view: meta-systems can settle some prior questions while acquiring their own limits.
14. Strange loop: only after the machinery is earned, the hierarchy folds back into itself.

## Persistent visual object

The 3D scene contains a proof machine with:

- particles for symbols and numerals
- rails for allowed transformations
- nodes for axioms, formulas, proof claims, and meta-level statements
- branching paths for proof search
- a returning diagonal path for self-application
- a dark gap for a statement not reached by the theorem generator

The same visual entities persist and are reclassified as the user scrolls. This continuity makes the mathematical transitions causal rather than decorative.

## Source and rigor labels

Each explanatory block carries one of these source labels:

- `GEB`: Hofstadter's framing and terminology, especially MIU/TNT, figure-ground, Gödel numbering, jumping out of the system, and strange loops.
- `STANDARD`: standard mathematical formulation or proof qualification.
- `TOY MODEL`: an intentionally simplified machine used to make a mechanism manipulable.
- `VISUAL METAPHOR`: a visual correspondence, not a proof.

The central construction is explicitly marked as a pedagogical diagonal model. The page does not claim that the toy machine is a full formalization of TNT or PA.

## Ending

The final state strips the environment back to eight statements. The user can activate each statement to test their understanding. The page ends with the mechanism, not a promotional summary.
