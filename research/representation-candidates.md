# Representation candidates

## 1. Self-reference

Candidate representations:
- graph of a statement pointing to itself
- recursive visual loop with an object containing its own description
- game where the user is asked to explain the rules that created the current state
- formal proof browser that lets a proposition mention the proving procedure
- musical idea in which a motif references the process that generated it

What each representation makes visible:
- direct reference vs indirect reference
- the moment where description crosses into the thing described
- the difference between an external observer and a system embedded in itself

## 2. Recursion

Candidate representations:
- tree growth simulation with branching parameters
- procedural graphics that redraw at increasing depth
- recursive text generation that nests phrases inside themselves
- musical canon where voices enter at different offsets
- program-like state machine that calls itself

What it reveals:
- how repeated local rules produce large-scale complexity
- how recursion and repetition differ
- how a small rule can generate an enormous state-space

## 3. Meaning and formal systems

Candidate representations:
- symbol-to-symbol mapping environment
- two-layer system where syntax is visible and meaning can be toggled
- translator between formal notation and natural language
- interactive proof editor
- dynamic semantics editor where changing interpretation changes the apparent truth of the same string

What it reveals:
- meaning emerges from relation, not raw token identity
- form and interpretation are distinct but connected

## 4. Figure and ground

Candidate representations:
- toggle between foreground and background in a recursive image
- dual-layer visual system where the user can choose what counts as the figure
- graph-theoretic view of a set and its complement
- sound layer where melody and accompaniment swap role
- semantic system where a proposition changes identity depending on context

What it reveals:
- what is counted as the “thing” depends on the observer’s level
- the same data can be structured in multiple ways

## 5. Gödelian incompleteness

Candidate representations:
- proof search that builds statements about the system from within the system
- a machine that generates a string that says “this string is not provable”
- a visual dependency graph of theorem, meta-theorem, and proof procedure
- interactive symbolic model with explicit axiom and rule layers
- formal system sandbox in which the user tries to “escape” via self-reference

What it reveals:
- there is no clean external vantage point from which the system is fully complete
- the system can reason about itself only by becoming more complex

## 6. Levels of description

Candidate representations:
- stack of nested descriptions that can be dragged up and down
- layers of program, compiler, operating system, user interface
- nested maps of a city or an organism at different abstraction levels
- multi-scale visual world whose rules change at each level
- musical score that shows motif, harmony, and orchestration as different descriptions of one object

What it reveals:
- boundaries between levels are often arbitrary or emergent
- a “whole” can be differently represented at multiple scales

## 7. Strange loops

Candidate representations:
- hierarchy that folds back into itself when a user manipulates a control
- network in which a node’s label changes the rules of the surrounding system
- recursive interface whose controls are generated from prior choices
- visual chamber where a level describes the level below it and vice versa
- generative music where each variation alters the original pattern

What it reveals:
- the observer becomes part of the observed
- the system can create feedback that is not merely circular but topologically entangled

## 8. AI and mind

Candidate representations:
- frame-based memory environment
- knowledge graph that changes when the agent reasons about itself
- a simulated “blocks world” where a machine and a human interact
- a multi-agent system in which each agent has a model of others
- generative thought-lab where context and representation determine what counts as understanding

What it reveals:
- thinking is not just symbol manipulation but context-sensitive relationship management
- intelligence may be a matter of layered models rather than a single monolithic process

## Strongest representation principle

The deepest representation is not necessarily the one that looks most elegant. It is the one that makes a hidden relationship perceptible.

The strongest candidate for the project is therefore a multi-layered computational lab where the same underlying rule is expressible as:

- mathematical string transformation
- visual recursion
- musical transformation
- self-referential proof process
- nested hierarchy simulation

This would let the user see that one rule can produce many distinct but structurally related experiences.
